This searches for public web pages; results can include unofficial sources. Folio checks site rules before inspecting a selected result and does not bypass logins, paywalls, DRM, or other access controls.

Inspect a manga website

Paste a public website or manga page URL. The crawler checks robots.txt before inspecting an HTML page.

PUBLIC PAGES
This crawler is intentionally respectful: no login/paywall circumvention, DRM bypass, or forced access. Websites that disallow crawling, require a sign-in, or block automated requests will not be bypassed. Generic detection is heuristic, so some sites need dedicated adapters.

Saved websites

Sources you have chosen to keep. Inspect them again to refresh discovered titles and chapters.

How source discovery works

The generic crawler reads a publicly accessible HTML page and looks for title metadata, cover images, same-site manga links, and chapter-like links. Websites with unusual layouts, script-rendered catalogs, CAPTCHAs, or image protections may need a custom adapter. Discovery is not a guarantee that every title on a site will be found.
